GitHub Pages 배포 가이드

이 자료는 "다음 단계" 자료예요.
오늘 재미나이로 만든 HTML 파일을 영구 URL로 배포하고 싶을 때 사용하세요. GitHub 계정만 있으면 무료로 운영할 수 있어요.
방식 1
캔바 코드
공유 버튼 클릭 한 번. 별도 설정 없음.
클릭 1번
방식 2
재미나이 캔버스
공유 링크 복사. 임시 링크라 장기 보관 어려움.
5분
방식 3
GitHub Pages ←
영구 URL. 여러 파일 관리 가능. 찰리쌤 방식.
이 가이드
STEP 1 GitHub 계정 만들기 — github.com
1
github.com 접속 → Sign up 클릭
이메일·비밀번호·사용자명 입력. 사용자명이 나중에 URL에 포함돼요.
사용자명 예시
hischarlie → hischarlie.github.io
2
이메일 인증 완료
가입 후 인증 메일 확인. 클릭하면 바로 사용 가능.
이미 계정이 있다면 STEP 1 건너뛰고 STEP 2로 바로 가세요.
STEP 2 저장소(Repository) 만들기
1
오른쪽 상단 + 버튼 → New repository
2
저장소 이름 입력
수업용 게임 모아두려면 이름을 의미있게 짓는 게 좋아요.
Repository name
history-games 예시
3
Public 선택 → Add a README file 체크 → Create repository
Public으로 해야 GitHub Pages 무료 사용 가능.
설정 확인
○ Private ● Public
☑ Add a README file
STEP 3 HTML 파일 업로드
1
재미나이 캔버스에서 HTML 파일 저장
캔버스 오른쪽 상단 → 다운로드 → 파일명 확인
파일명 예시 (한글·공백 금지)
uibyeong-quiz.html → OK 의병 퀴즈.html → NG
2
저장소에서 Add file → Upload files
버튼 위치
Code ▼ Add file ▼ ⊕ Upload files
3
파일 드래그 or 파일 선택 → Commit changes 클릭
하단 커밋 버튼
Commit changes
STEP 4 GitHub Pages 활성화 — 딱 한 번만 하면 됩니다
1
저장소 상단 Settings 탭 클릭
2
왼쪽 메뉴 → Pages
3
Source → Deploy from a branch → main 선택 → Save
Branch 설정
main / / (root) Save
4
1~2분 기다리면 URL 생성 완료
https://hischarlie.github.io/history-games/uibyeong-quiz.html
Pages 설정은 저장소당 한 번만. 이후 파일 추가·수정은 STEP 3만 반복하면 돼요.

FAQ 자주 묻는 질문
파일 수정하면 URL도 바뀌나요? +
URL은 바뀌지 않아요. 같은 파일명으로 다시 업로드하면 자동으로 업데이트돼요. 1~2분 후 새로고침하면 반영됩니다.
게임 파일을 여러 개 올릴 수 있나요? +
네, 하나의 저장소에 여러 HTML 파일을 올릴 수 있어요. 찰리쌤처럼 10개 게임을 한 저장소에서 운영하는 것도 가능해요. 파일마다 URL이 다르게 생성됩니다.
학생 데이터(점수 등)도 저장되나요? +
GitHub Pages는 정적 호스팅이라 데이터 저장이 안 돼요. 학생 결과를 수집하려면 Google Forms + GAS 연동이 필요해요. 오늘 강의 범위를 넘어서는 내용이에요.
비용이 드나요? +
Public 저장소 + GitHub Pages는 완전 무료예요. 저장 용량 제한(1GB)이 있지만 HTML 파일만 올리면 거의 제한에 걸리지 않아요.
index.html이 뭔가요? 꼭 필요한가요? +
index.html은 폴더 주소로 접속했을 때 자동으로 열리는 파일이에요. 없어도 되지만, 게임 목록 페이지를 만들고 싶다면 index.html을 만들어두면 편해요.
